# PlanSmart
PlanSmart is an all-in-one scheduling app designed for Android. By creating an account, users can access their plans seamlessly across different devices.

<pre>
This is a group project with 2 members.
  
- Individual work: Tag.kt, TagAdapter.kt
  
- Collaborative work: bucket_list.kt, daily_goals.kt, todo_list.kt, MainActivity.kt, XML
</pre>
